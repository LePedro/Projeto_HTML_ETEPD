+-- 5. FLUXO DO CARRINHO
    |
    +-- livros.html / quadrinhos.html
    |       |
    |       +-- botão "Adicionar ao carrinho"
    |               |
    |               v
    +-- assets/js/script.js
    |       +-- salva os itens no localStorage do navegador
    |       +-- recupera os itens e calcula o total
    |               |
    |               v
    +-- carrinho.html
            +-- mostra os produtos e o total da compra

Observação:
O SQL representa um modelo de banco de dados do projeto. Pelos arquivos analisados,
o carrinho utiliza localStorage no navegador; não há evidência de conexão ativa
entre as páginas HTML e o banco SQL.
